⚡ Adjectives (kata sifat)

🧱 Sentence Starters

It is a / an … It has … It connects / sends / stores … This device / tool / room … We use it to / for …

🏗️ Generic Structure

1 · IDENTIFICATION — kenalkan objeknya.
"A router is a network device."
2 · DESCRIPTION — ciri, fungsi, bentuk.
"It connects two networks. It is fast and wireless."

🔧 Simple Present Tense

• It is a small device.
• It has eight pins.
• A switch connects many computers. (pakai -s/-es)
• They carry data every day.
