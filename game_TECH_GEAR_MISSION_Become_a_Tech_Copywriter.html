📚 LEARNING CORNER

DESCRIPTIVE TEXT — Generic Structure

  1. Identification — introduce the object (what it is).
  2. Description — describe its features, parts, and function.

USEFUL LANGUAGE

It is …It has …It comes with … It supports …It is equipped with …It is made of …

HONESTY RULE 🤝

Informative writing uses facts and numbers. Claims like “the best in the world” or “never breaks” are exaggerated unless there is real evidence. A good copywriter never tricks the buyer.

❓ HOW TO PLAY

  1. Complete 5 levels to become a Senior Tech Copywriter for TECHZONE.
  2. Each correct answer gives XP + Score. Watch the XP cap per level!
  3. You have ❤️ 3 lives. Wrong answers cost 1 life. At 0 lives → Mission Paused (progress is NOT deleted).
  4. You have 💡 3 hints. Each hint costs 20 XP.
  5. Answer 3 in a row → COMBO x3 bonus. 5 in a row → SUPER COMBO x5. No mistakes in a level → PERFECT LEVEL!
  6. Keyboard: press 1–4 to answer multiple choice. All buttons work with Tab + Enter.
  7. Level 2 has a 90-second timer. Level 5 checks your writing word count (50–100 words).

🎯 LEARNING OBJECTIVES

Setelah bermain, kamu diharapkan mampu:

  1. Mengenali nama perangkat komputer & jaringan dalam bahasa Inggris.
  2. Menjelaskan fungsi perangkat menggunakan bahasa Inggris.
  3. Mengidentifikasi adjective untuk mendeskripsikan benda.
  4. Menggunakan noun phrase dalam deskripsi perangkat.
  5. Menggunakan simple present tense dengan benar.
  6. Mengidentifikasi bentuk, ukuran, warna, bahan, spesifikasi, fungsi, konektivitas, isi kemasan, dan garansi.
  7. Membedakan product description informatif dengan yang berlebihan/menyesatkan.
  8. Mengevaluasi kualitas sebuah product listing.
  9. Menyusun product description sederhana yang informatif, menarik, dan jujur.
  10. Melatih critical thinking, creativity, communication, collaboration, dan kejujuran.
